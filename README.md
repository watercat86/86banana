# なんちゃってブラウザ

提供されたHTMLを、ローカルサーバーで起動できる形にしました。外部フレームワークやRenderは不要です。

## 起動

Python 3 が入っている環境で、リポジトリのルートから実行します。

```bash
python3 server.py
```

ブラウザで http://127.0.0.1:8000/ を開いてください。Windowsでは `python server.py` でも起動できます。

別のポートを使う場合は、`server.py` の `8000` を変更するか、次のコマンドでも動かせます。

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

## 注意

これは静的HTMLをローカル配信する構成です。表示先サイトが `X-Frame-Options` / CSP でiframeを禁止している場合、外枠側では回避できません。検索機能は `r.jina.ai` 経由のため、ネットワーク環境やサービス側の制限により動作しない場合があります。
